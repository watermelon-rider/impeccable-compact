# Apply an expressive direction

Use this only after a style has been selected with `bold select`.

## 1. Resolve truth

Inspect PRODUCT.md, DESIGN.md, the target, and the user's brief. A selected
style is visual direction, never product truth.

Choose the surface mode:

- **Persuade:** expression earns attention and makes the offer unmistakable.
- **Operate:** expression may shape the shell, but controls and data remain
  conventional and fast.
- **Read:** expression supports pacing and memory without harming legibility.
- **Experience:** the artifact may lead; interface chrome recedes.

## 2. Commit three layers

Apply the selected style consistently at:

1. **Composition** — the main spatial move and reading path.
2. **Material** — type, color, borders, depth, texture, and imagery language.
3. **Behavior** — one signature interaction and one motion grammar.

Pick one dominant expressive move. Supporting elements stay quiet enough for it
to read. Avoid collecting unrelated effects.

## 3. Protect the floor

Read `craft-floor.md` immediately before the first edit. Content remains
traceable to supplied truth.

## 4. Build and verify

Build the complete real surface. Run the detector exactly once, apply its
findings in one patch batch, then inspect desktop and mobile renders once. Do
not reread the target or rerun the detector after that correction.

Do not generate comps, plates, style variants, or a second review pipeline.
Do not patch one property at a time; one complete patch is the correction budget.
